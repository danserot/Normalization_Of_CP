## Измерение памяти

Все три контейнера приложения: backend с рабочим процессом и Tesseract, постоянно загруженная Qwen, frontend/nginx. CPU, два потока модели, контекст 2048, batch 128, один слот, JSON Schema, максимум 256 токенов ответа.

Единицы десятичные: 1 ГБ = 1 000 000 000 байт. Таблица — сумма индивидуальных максимумов `memory.current` в окне обработки; целевой шаг 50 мс, возможен джиттер планировщика. Для быстрых файлов включены ближайшие граничные отсчёты. Дополнительно прочитан точный накопленный `memory.peak` ядра каждого контейнера: максимальная сумма **2,200,002,560 байт ≈ 2.200 ГБ**. Она включает загрузку модели и даёт консервативную верхнюю оценку одновременного пика. В финальном прогоне swap модели — 0 байт. Размер GGUF не использовался вместо измерения RAM.

Лимит 3 ГБ соблюдён для контейнерного приложения на этом наборе. Предпочтительные 2 ГБ достигнуты не во всех случаях. Не измерены браузер пользователя, Docker Desktop/VM и сторонние контейнеры: эти цифры нельзя выдавать за потребление всего компьютера или всех процессов браузера. Защитные лимиты Compose в сумме 2796 МиБ ≈ 2,93 ГБ, swap отключён; экстремальный файл может получить ошибку ограничения ресурсов.

Полные данные: `test-results/memory.json`; ответы API и цитаты: `test-results/*.result.json`. Каталог игнорируется Git; воспроизводимый генератор и benchmark входят в репозиторий.

## Границы проверки интерфейса

Страница открыта и визуально проверена в Edge на localhost; показан локальный режим. Полный путь загрузка → редактирование → подтверждение через браузер **не проверен**: расширение браузера отклонило `fileChooser.setFiles` (`Not allowed`), требуется разрешение доступа расширения к file URL. Изменение этого разрешения пользователю предложено; оно не менялось автоматически. HTTP-путь загрузки и сохранения проверен отдельно, как указано выше.

## Что требует ручной проверки

Плохие/перекошенные фотографии, многоуровневые или объединённые заголовки, таблицы без однозначных заголовков, вложенные таблицы DOCX, нестандартный JSON, формулы без Excel-кэша, сложный НДС/скидки, OCR-ошибки, значения модели, конфликтующие реквизиты и неоднозначная запись числа. Неподдерживаемая структура возвращает текст с предупреждением, без выдуманного количества/цены.
